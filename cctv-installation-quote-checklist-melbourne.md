# CCTV Installation Quote Checklist for Melbourne Homes

Use this checklist to compare security camera installation quotes on the same scope. A camera count by itself does not tell you what equipment, cabling, storage or setup is included.

**About this checklist:** Rhodium Security publishes this resource and provides security equipment and installation services in Melbourne. It is a practical buyer checklist, not an independent review or a quote. Confirm the exact equipment, scope and current terms for your property.

## Before you request a quote

Prepare a simple property sketch. Mark the entrances and approaches you want covered, the likely recorder location, and any detached garage or outbuilding. For each camera position, note:

- What the camera should show, such as a person approaching a door or a vehicle entering a driveway.
- Approximate camera-to-subject distance and proposed mounting height.
- Obstructions such as eaves, trees, fences, parked vehicles or neighbouring structures.
- Lighting after dark, including porch lights, headlights and areas that remain unlit.
- Whether the location is single-storey, multi-storey or difficult to access.

Take photos from likely camera positions in daylight and after dark. Include notes about existing cameras, cabling, recorder model and network equipment if you want an installer to assess whether anything can be reused.

## Compare equipment line by line

Ask each provider to identify the complete model number and quantity for every camera and recorder. Model suffixes can indicate a different lens or feature, so avoid comparing products by brand name alone.

Check whether the written scope specifies:

- Camera model, resolution, lens and intended viewing area.
- Recorder model and the number of channels available.
- Whether a hard drive is included, its capacity, and the recording settings used for any storage estimate.
- Mounting hardware, weather protection and any junction boxes.
- Network equipment, power supplies or other components required for the proposed design.
- Any app, remote-viewing or account setup included in handover.

Ask for a storage estimate based on the actual camera count, selected resolution, bitrate, recording schedule and scene activity. No single drive size guarantees a fixed number of recording days across different setups.

## Confirm what installation includes

A quote should make the installation work understandable before you book. Ask the provider to state whether the price includes:

- Cable supply, approximate cable routes and terminations.
- Drilling, sealing and making-good work, if applicable.
- Access equipment or additional labour for difficult positions.
- Camera aiming, recorder configuration and recording setup.
- Mobile app or remote-viewing setup, if requested.
- A demonstration of playback, searching and exporting a clip.
- Handover notes and any exclusions or customer-preparation requirements.

Clarify who supplies power points, network connections and any building work outside the quoted scope. Ask how variations are approved if the actual cable route or site access differs from the plan.

## Ask about ongoing costs and access

Keep one-off equipment and installation costs separate from any recurring service, cloud storage or subscription fees. Ask whether remote viewing depends on an internet connection, what features continue locally if the connection drops, and how user access can be changed when household members or staff change.

Decide who should be able to view or export recordings. Use strong, unique passwords and enable multi-factor authentication where the product supports it. Keep cameras aimed at areas you are entitled to monitor and consider privacy around neighbours and shared spaces; requirements depend on the circumstances, so seek appropriate advice if unsure.

## Compare quotes using one scope

Use the same brief for each provider and ask them to list assumptions and exclusions. A simple comparison table can include:

This makes it easier to see whether two quotes describe the same system. If a model is substituted, request the revised model number and scope in writing before accepting the change.
